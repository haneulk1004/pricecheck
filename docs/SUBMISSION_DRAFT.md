# PRICE_CHECK 제출 준비 초안

완료 목표: 2026-09-20 13:00 KST (사용자 지정, 대회 공식 마감과 별개).
공식 제출 양식의 필수 항목·분량·영상 요구는 미확인. 아래 내용은 양식 확인 후 조정한다.

## 한 줄 소개
제품 사진에서 브랜드·제품명·용량을 식별하고, 출처가 있는 온라인 가격을 찾아 매장 구매 판단을 돕는 웹 앱.

## 해결하려는 문제
매장에서 제품명을 다시 입력하고 판매처마다 용량·수량·배송 조건을 비교하는 번거로움을 줄인다. 비슷한 제품이나 묶음 상품 가격을 혼동하지 않도록 제품 확인 단계를 둔다.

## 주요 흐름
사진 촬영/업로드 또는 직접 검색 → 제품명·옵션 확인 → 매장 가격검증 → 가격·배송 조건·조사 시각 확인 → 출처 열기.

## AI 활용
사진 기반 제품 식별과 Google 검색 근거가 붙은 가격 조사. 숫자 가격에 원본 검색 인용이 없으면 결과에서 제외한다. 용량·수량과 판매처 출처를 추가 검증한다. 같은 요청은 24시간 캐시를 재사용한다.

## 확인된 범위
- 사용자 iPhone: 갈아만든 배 340ml 사진 인식부터 가격 조회까지 성공. 다나와 340ml 1개 상품 페이지와 가격·배송비 일치 확인 (9월 16일 당시).
- Aesop 핸드 밤 75ml 사진 인식 및 용량 보존 확인. 가격 조사는 55초 시간 초과가 발생해 개선 검증 중.
- 출처가 카테고리로 이동하거나 수량이 모호한 확인 사례는 임시 제외 규칙 적용.
- 모든 상품이나 모든 출처 연결의 정확도를 보장하는 서비스로 설명하지 않는다.
- 리셀 모드는 구현돼 있으나 사이즈별 원문 대조가 남아 있어 검증 완료 기능으로 홍보하지 않는다.

## 90초 데모 초안
1. 매장에서 가격을 비교하는 문제 소개 (10초).
2. 갈아만든 배 사진 입력과 340ml 확인 (20초).
3. 가격 조사 결과에서 배송비·조사 시각 설명 (20초).
4. 다나와 원문에서 상품·수량 대조 (20초).
5. 검증되지 않은 가격은 제외하며, 외부 검색 실패 시 다시 시도할 수 있음을 설명 (20초).
데모는 실제 응답으로 촬영한다. 과거 가격을 현재 실시간 결과처럼 편집하지 않는다.
