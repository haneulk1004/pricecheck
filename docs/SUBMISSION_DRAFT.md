## 실제 제출 양식
사용자가 제공한 전체 제출 화면 기준: 대표 이미지, 제목, 해결하려는 문제, AI 활용 방식 및 결과(500자), 사용 AI 및 기술 스택, 서비스 링크, 스크린샷(최대 5개, 16:9). 영상 입력란 없음.

## 해결하려는 문제
매장에서 발견한 제품의 정확한 모델·용량을 다시 검색하고, 온라인 가격과 배송 조건을 여러 판매처에서 비교해야 하는 번거로움을 줄이고자 했습니다.

## AI 활용 방식 및 결과 초안 (500자 이내)
Google Gemini로 사진 속 제품의 브랜드·제품명·용량을 식별하고, 사용자가 확인·수정한 정보로 Google Search Grounding을 활용해 공개 가격과 출처를 찾습니다. 검색 결과의 숫자 인용, 제품명·모델·용량·수량을 검사하고, 판매처 상품 데이터와 가격을 대조하도록 구현했습니다. 검증되지 않은 후보는 제외하며 판매처 검색 링크로 직접 확인할 수 있습니다. OpenAI Codex를 코드 구현·오류 분석·자동 테스트에 활용했습니다. 외부 사이트의 접근 제한과 상품 데이터 제공 방식에 따라 가격 결과가 없거나 검색이 지연될 수 있습니다.

최종 배포 검증 후 실제 동작과 일치하는지 재검토할 것. 특정 제품명은 제출 소개에 넣지 않음.

## 선택할 기술 태그
React, ChatGPT, Gemini, Vercel. 실제 사용하지 않은 프레임워크는 선택하지 않음.

## 검증 기록과 한계
- 사용자 휴대폰에서 사진 인식 및 용량 확인 성공 사례가 있음.
- 가격 API 응답 성공만으로 정확성 검증 완료로 판단하지 않음.
- 사용자 테스트에서 다른 브랜드 목록 및 종료된 행사로 연결되는 출처 오류가 발견됨.
- 후속 수정: 브랜드·제품명·모델·옵션 검사, 출처 최종 URL 및 독립된 Product/Offer 데이터 대조, 잘못된 캐시 재검증과 제거. 원문에서 동일 가격을 확인할 수 없으면 결과를 표시하지 않음.
- 구조화 데이터가 없는 판매처, 번역명 변형, 접근 제한은 결과 누락 원인이며 전체 상품 지원 또는 최저가 보장을 주장하지 않음.
- 원문 검증은 상품 표시 가격을 대상으로 하며 쿠폰·배송비·최종 결제 금액 보장은 아님.
- 리셀 사이즈별 실제 거래 검증은 완료되지 않음.
