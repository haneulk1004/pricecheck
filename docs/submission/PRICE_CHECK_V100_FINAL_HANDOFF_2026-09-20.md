## 2. 서비스 개요

PRICE_CHECK V100은 사용자가 매장에서 발견한 제품을 촬영·업로드하거나 제품명을 직접 입력하면 AI가 제품 정보를 식별하고, 공개 웹 출처를 이용해 매장 가격과 온라인·리셀 가격을 확인하도록 돕는 서비스입니다.

서비스 흐름:

1. 제품 사진 촬영·업로드 또는 제품명 직접 입력
2. AI가 브랜드·제품명·용량·확인 가능한 모델 정보를 식별
3. 사용자가 식별 결과를 확인하거나 수정
4. `매장 가격검증` 또는 `리셀 시세` 선택
5. Google Search Grounding으로 공개 판매가 조사
6. 제품·용량·수량·사이즈 및 가격 근거가 일치하는 결과만 표시
7. 검증 근거가 부족하면 가격을 추정하지 않고 결과에서 제외

## 3. 제출 최종 문구

### 제목

PRICE_CHECK V100 — 사진으로 찾고 출처로 검증하는 AI 가격 확인 서비스

### 해결하고자 한 문제

매장에서 본 제품의 정확한 온라인 가격을 찾기 어려운 문제를 해결하고자 했습니다.

### AI 활용 방식 및 결과

매장에서 마음에 드는 제품을 발견해도 적정한 가격인지 확인하려면 여러 쇼핑몰을 일일이 찾아봐야 합니다. 이 과정을 줄이기 위해 사진을 촬영하거나 올리면 Gemini가 브랜드와 제품명, 용량을 파악하고, 사용자가 직접 입력한 제품명도 확인할 수 있게 만들었습니다. 이후 Google Search Grounding으로 공개된 판매가와 출처, 배송 조건을 찾아 비교합니다. 모든 제품의 최저가를 보장하거나 AI가 가격을 추측하지는 않습니다. 제품명·용량·수량과 근거가 일치하는 가격만 보여주고, 확실하지 않은 결과는 제외합니다. 같은 조건의 결과는 24시간 재사용하며, 새 조사는 IP당 하루 10회·전체 300회로 제한했습니다. ChatGPT Codex로 기능 구현과 오류 수정, 자동 테스트, 배포 검증을 진행했습니다.

- 배포: Vercel

## 5. 검색 제한과 사용자 안내

- 새 실시간 가격 조사: 동일 IP 기준 하루 10회
- 서비스 전체 새 조사: 하루 300회
- 사용량 초기화: 한국시간 자정
- 동일 제품·모드·사이즈의 성공 결과: 24시간 재사용, 재조회 시 횟수 차감 없음
- 가격 조사 제한은 사진 인식과 제품 정보 확인 단계와 별도
- 검증 가능한 근거가 없으면 가격을 추정하지 않고 결과를 표시하지 않음
- 표시 가격은 최저가를 보장하지 않음
- 배송비·옵션·재고·거래 조건은 연결된 판매처에서 최종 확인 필요
- 외부 검색 상태에 따라 응답이 지연되거나 결과가 없을 수 있음
- 리셀 모드는 선택 사이즈와 일치하는 근거가 있어야 가격 표시

## 6. 검증 상태

- 자동 테스트: 87개 통과, 실패 0개
- 제품 사진의 과도한 크기·위조 형식·지원하지 않는 형식 차단
- 사진에서 보이지 않는 모델/SKU의 임의 추론 방지
- 제품명·브랜드·용량·수량·사이즈 불일치 결과 차단
- 가격 숫자를 직접 뒷받침하지 않는 출처 차단
- 판매처 이름과 출처 도메인 불일치 결과 차단
- 검색·카테고리·종료된 행사 페이지를 상품 가격 근거로 사용하지 않도록 차단
- 리셀 exact-size 근거가 없는 가격 차단
- 실패 결과 캐시 방지 및 provider 실패 시 조사 횟수 환불
- 동일 조건 결과 24시간 캐시 및 한국시간 기준 사용량 초기화 검증
- 공개 서비스 비로그인 접속 확인

## 7. 확인된 한계

- 제품 식별보다 정확한 실시간 가격 검색의 성공률이 낮음
